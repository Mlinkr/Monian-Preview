# Monian · 拼图预览生成器

> 上传一个文件夹，自动拼成一张带水印的高清预览长图。纯前端、无需服务器、照片不会离开你的设备。

![界面预览](docs/screenshot.jpg)

## 这是什么

做素材展示时，常常要把一组剧照、写真拼成一张"预览长图"，再在每张图上打上作品名、上架时间、价格、群号等信息。手动用 PS 一张张排，慢且容易出错。

这个工具把这件事变成两步：

1. 把文件夹拖进来
2. 点导出

程序会自动读出文件夹名和文件时间，套用你保存好的水印格式，排好版，生成一张可以直接发出去的预览图。

## 功能

| 功能 | 说明 |
| --- | --- |
| **文件夹批量导入** | 选中文件夹即可，按文件名自然排序；也支持直接拖拽、多选图片 |
| **提取即水印** | 文件夹名如 `【20261027】张艺兴` 自动拆成 时间 + 名称，张数自动填好；这三个值就在 **01 卡片**下方直接开关、调色、调字号透明度、选九宫格，**均支持占位符**；不符合格式时时间取文件修改日期 |
| **水印一次输入，长期复用** | 所有水印文字保存在本机浏览器，下次打开自动带出；改文字即可，或一键清空重输 |
| **占位符** | `{folder}` 名称、`{date}` 时间、`{index}` 序号、`{count}` 张数，自动替换 |
| **每张图独立水印** | 九宫格定位 + 自由定位（横纵百分比滑条）、独立字号、独立透明度、**独立文字颜色**（适配各种底图），可加任意多条 |
| **整张图水印** | 用于在整图角落加品牌、群号等，同样支持文字与花纹两种 |
| **图片水印** | 上传 PNG 等透明底图案。**与素材同为 16:9 时自动等比铺满每张图**；其他比例可选平铺或单张，调尺寸、透明度、每行重复、旋转 |
| **图层顺序固定** | 底图（有的话）→ 素材拼接图 → 图片水印 → 文字水印，从下往上叠。图片水印与文字水印可以同时存在，各自独立调；**文字永远在最上层**，不会被水印图盖住 |
| **底图三模式** | ①纯色底图（可自选颜色，带标题栏，默认）②自定义底图（上传自己设计、带图案或水印的底图，四个滑块框出放置区域）③无底图（图片直接拼接） |
| **可折叠面板** | 01–05 五张卡片全部可收起/展开，状态自动记住，小屏也能随时看到预览 |
| **衬线宋体字体** | 界面与输出统一使用思源宋体（Noto Serif SC），细笔画带衬线，接近示例图质感；已内置，不依赖网络字体 |
| **四种版式** | 上下拼接 / 两列 / 三列 / 四列，列数可 1–6，间距、留白、圆角可调 |
| **16 : 9 永不裁剪** | 素材按 16:9 单元格完整显示，等比缩放、绝不裁剪或拉伸；非 16:9 的图会留底色边 |
| **高清导出** | 1080 / 1600 / 2000 / 2400 / 3000 px 宽，JPG / PNG，画质可调 |
| **全端可用** | 电脑、安卓、iPhone、iPad 自适应，可"添加到主屏幕"当 App 用 |
| **隐私** | 所有运算在浏览器内完成，图片不上传任何服务器 |

## 使用方法

1. **选择素材** — 点「选择文件夹」。文件夹名为 `【20261027】张艺兴` 时，程序自动拆出 **时间 20261027** 与 **名称 张艺兴**；也支持 `20261027张艺兴`、`[2026-10-27] 婚礼跟拍` 这类写法。没有日期前缀时，时间取文件修改日期。
   - 手机浏览器不支持选文件夹时，用「选择图片」多选，再手动填写名称和时间。
   - 选错了不用一张张删，缩略图下方有 **「🗑 一键清空全部素材」**，一下清干净重新选。
2. **调素材水印（01 卡片）** — 导入后名称、日期、张数会自动带出，这三条和水印设置**在同一块面板里，不再分开**：
   - 每条第一行就是**内容输入框**（名称 / 日期 / 张数），改这里图片上的字会跟着变；右侧 `×` 一键清空
   - 第二行是颜色、九宫格位置、字号、透明度（右侧显示百分比），点最左边的 `○ / ●` 开关该条
   - 第三行是**水印文字，默认就是占位符** `{folder}` / `{date}` / `{count}`，可以随意改成固定文字或混合文本，例如 `【{date}】{folder} · 共{count}张`
   - 支持全部占位符：`{folder}` `{date}` `{count}` `{index}`
3. **加额外水印（02 卡片）** — 这里只放你自己手加的：
   - 「＋ 添加文字水印」：纯文本，可调颜色、位置、字号、透明度；支持占位符
   - 「＋ 添加图片水印」：上传 PNG 透明底图案，**不压缩、按原尺寸载入**。如果是 16:9（和素材同比例），会自动等比铺满每张图片，只留透明度可调；其他比例可选平铺/单张，调尺寸、每行重复、旋转
   - 「每张图上」作用到每张照片，「整张图上」作用到整张长图（含标题与留白）
4. **选底图（03 卡片）** — 三种模式任选：
   - **纯色底图**（默认）：点色块或取色器换底色，可填「大标题」和「右上角信息」（每行一条，如价格、联系方式）。
   - **自定义底图**：上传自己设计好、带图案或个人水印的底图，用「图片放置区域」的上/右/下/左四个百分比，让照片正好嵌进空白处。勾选「显示参考线」可以看到框选范围（不会被导出）。
   - **无底图**：不加标题栏和留白，图片直接拼接排列。
   - 03、04 两张卡片点标题即可收起/展开，收起状态会自动记住。
5. **调版式** — 点「上下拼接 / 两列 / 三列 / 四列」，或拖列数滑块，右侧实时预览。
   - **比例锁定 16 : 9**：所有单元格都是标准 16:9，图片等比缩放完整显示，**永远不裁剪、不拉伸**。如果原图不是 16:9，多出来的地方会显示底色边，不会切掉画面。
6. **导出** — 选宽度和格式，点「导出图片」。也可以点「复制」直接粘贴到聊天窗口。

### 水印排版建议

- 字号保持在格子宽度的 3%–5%，配合 `左下` 位置和较低透明度，既看得清又不会挡住人物。
- 想要文字在浅色画面上也清楚，程序会自动在图片底部加一层很淡的黑色渐变衬底。
- 位置排不下时，同一侧的多条水印会自动缩小字号，避免溢出。
- 想放到任意位置：点水印右侧「位置」→ 切到「自由定位」，用横向、纵向两个滑条（0–100%）精确摆放。

## 部署到 GitHub Pages（免费、可长期使用）

### 方式一：网页上传（不用命令行）

1. 在 GitHub 新建一个仓库，例如 `monian-preview`，设为 **Public**。
2. 进入仓库，点 **Add file → Upload files**，把本项目里的这些**文件和文件夹**整体拖进去：
   ```
   index.html
   manifest.json
   .nojekyll
   assets/
   ```
3. 提交后进入 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main` / `root`，保存。
4. 等 1 分钟左右，访问 `https://你的用户名.github.io/monian-preview/` 即可。

### 方式二：命令行

```bash
git clone https://github.com/你的用户名/monian-preview.git
cd monian-preview
# 把本项目文件复制进来
git add .
git commit -m "feat: Monian 拼图预览生成器"
git push
```

然后在仓库 **Settings → Pages** 里开启 Pages。

### 以后更新

改完文件后 `git add . && git commit -m "更新" && git push`，Pages 会在 1 分钟内自动重新发布。如果是网页上传的方式，直接在 GitHub 里替换对应文件即可。

## 技术说明

- **零依赖**：原生 HTML / CSS / JavaScript，不用构建，改完刷新就生效。
- **单一渲染管线**：预览和导出调用同一个 `MN.Render.paint()`，只是传入的宽度不同，所以预览看到什么，导出就是什么。
- **高质量缩放**：缩小图片时按 2 倍逐级降采样，避免直接 `drawImage` 造成的锯齿和糊。
- **内存控制**：导入时把图片长边限制在 2600px，既保证 3000px 输出够用，也避免一次导入几十张原图把手机内存打爆。
- **持久化**：文字类设置存 `localStorage`；模板原图存 `IndexedDB`（避免超出 localStorage 容量）。

## 常见问题

**Q：为什么导出的图上文字有点小？**
调「字号」滑块，或减小列数。列数越多，单格越小，同样倍数的字号就越小。

**Q：HEIC 格式的图导入失败？**
浏览器无法解码 HEIC。先在手机里把照片导出为 JPG（iOS：设置 → 相机 → 格式 → 兼容性最佳），或截图后再用。

**Q：导出提示"尺寸过大"？**
长图有像素上限（单边 16384px）。降低输出宽度，或减少图片张数 / 增加列数。

**Q：换电脑或换浏览器后水印没了？**
设置保存在**本机浏览器**里，换设备不会同步。重新输入一次即可。

**Q：模板调不准位置？**
勾选「显示放置区域参考线」，四个滑块分别对应上、右、下、左的百分比，配合预览慢慢调。
